# L 的房间 · 使用说明

《Empty Box：空盒子》的粉丝自制聊天页面，可以和 L 一对一聊天。不是官方页面。

- 网址：https://shikashikac.github.io/Ls-Room/
- 仅限已满 18 岁的人使用。（所以在聊天的时候不要告诉他你没满18岁，会影响体验）

## 使用前要知道的

这个页面需要你填**自己的 Claude API key**。

- API key 是 Claude 官方按用量收费的接口密钥，费用从你自己的账户里扣，作者不经手任何费用。
- 页面固定使用 **Claude Opus 5.5**。L 的语气、记忆和剧情细节都是按这个模型调的，为了保证效果，没有提供更便宜的选项。
- 其他 AI 服务的 key、各种“免费 key”在这个页面里都用不了。只有 Claude 官方的 API key 可以。

## 第一步：申请 API key

第一次接触的话，请先看 **[新手教程](新手教程.md)**，里面一步一步写了怎么注册、充值和创建密钥。下面是简略版。

1. 打开 Claude 开发者平台：https://platform.claude.com/ ，注册或登录。
   这和 Claude 聊天应用是两套账户，订阅了 Claude 会员不代表有 API 额度。
2. 给账户充值。先充几美元就够试用。
3. 在首页找到创建 API 密钥的入口。如果问你“代码在哪里运行”，选带钥匙图标的 **“其他位置”**。
4. 填写创建密钥的表单：
   - 名称：随便起，比如 `L-room`。
   - 到期时间：建议选 30 天。到期后密钥自动失效，更安全，之后再新建一个就行。
   - 其他选项保持默认。
5. 点“创建密钥”。完整的密钥**只显示这一次**，马上复制下来。
   密钥是以 `sk-ant-` 开头的一长串字符。没存下来的话无法再查看，只能重新创建。

## 第二步：打开页面，填写

1. 用手机或电脑的浏览器打开上面的网址。
2. 填你的名字，L 会这样叫你。
3. 勾选“我已满 18 岁”。
4. 把刚才复制的密钥粘贴到“你的 Claude API key”一栏。
5. 点“进去”，就可以开始聊天了。

小提示：

- 点一下对话框可以翻到下一句。
- 左下角的“照片”可以发图给他看。
- 右上角的“记录”可以翻看之前的对话。
- 屏幕右侧有“去酒吧”和“去画室”。去不去、去几次，后果自负！！！！
- 可以直接用手指点 L：点头发是摸头，点脸是摸脸，点肩膀到腰是碰他的身体。每个部位他都有好几种反应，多点几次会不一样。这些反应是即时的，不花 API 费用。
- 在画室里，右侧有“编头发”，可以给林创扎高双马尾、低双马尾、侧低马尾、高马尾、双麻花辫，画面会换成对应的样子。扎好以后可以换别的发型，也可以选“拆掉”恢复原样。

## 费用大概多少

按用量计费，没有月费。粗略估计，用 Opus 5.5 时**每条消息大约几美分**，聊得越久、每条带的上文越多，单条会略贵一些。发照片的那一条会更贵。

这只是估算，实际金额以开发者平台首页的“本月支出”为准，建议刚开始多看几次。

## 你的数据存在哪里

- 名字、聊天记录、L 记住的事、你的 API key，全部只保存在**你自己这台设备的浏览器里**。
- API key 和聊天内容只会发给 Anthropic（Claude 的开发公司）的服务器，用来生成回复。作者看不到，也收不到。
- 换设备、换浏览器或清除浏览器数据后，记录就没有了，需要重新填写。
- 想从头开始或更换密钥：在输入框里连续发送两次 `全部清空`。

安全建议：

- 不要把 API key 发给任何人，也不要截图发到群里。
- 给这个页面单独建一个密钥，设到期时间，不用了就在开发者平台上删掉它。

## 常见问题

**点“进去”没反应**
看一下按钮上方有没有红色提示。常见原因是没勾“我已满 18 岁”，或者粘贴密钥时带进了空格、换行。

**提示“这个 API key 用不了”**
密钥没复制完整、已过期或已被删除。回到开发者平台新建一个，重新填写。

**提示“发得太快了，或者 API 的额度用完了”**
等一会儿再试。还不行就去开发者平台看看余额。

**提示“连不上 Claude 的服务器”**
检查网络。部分地区和网络环境无法直接访问 Claude 的服务。

**L 忘了我以前说过的事**
他能原样记住最近的 60 条消息，更早的内容会被他整理成要点长期记住。很久以前随口说的小细节可能会被忘掉，重要的事可以再对他说一次。
