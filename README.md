# L 的房间 · 使用说明

《Empty Box：空盒子》的粉丝自制聊天页面，可以和 L，左见，林创 一对一聊天。不是官方页面。

- 网址：https://shikashikac.github.io/Ls-Room/


## 先看这里：你该看哪一份教程

这个页面需要你填**自己的 API key**（一串按用量收费的密钥），支持两家，选一家就可以：

| 你的情况 | 用哪一家 | 教程 |
|---|---|---|
| 人在中国大陆、香港、澳门 | DeepSeek | **[国内的宝宝看这里](教程-国内-DeepSeek.md)** |
| 人在海外，或者本来就能用 Claude | Claude | **[海外或者可以用 Claude 的宝宝看这里](教程-海外-Claude.md)** |

两条线路的区别：

- **Claude 线路**用的是 Claude Opus 5.5。L 的语气、记忆和剧情细节都是照着这个模型调的，效果最好，价格也更贵。
- **DeepSeek 线路**用的是 DeepSeek V4 Pro，开着深度思考。国内可以直接注册和付款，便宜很多；L 的感觉会和 Claude 线路有些差别，回复前要多等几秒。
- 页面会根据你填的 key 自动判断走哪条线路，不用自己选。
- 费用从你自己的账户里扣，作者不经手任何费用。各种“免费 key”和来路不明的 key 请不要用。

## 第一步：申请 API key

照着上面对应的那份教程做，拿到 key 以后回到这里继续。

## 第二步：打开页面，填写

1. 用手机或电脑的浏览器打开上面的网址，点一下屏幕。
2. 填你的名字，L 会这样叫你。
3. 勾选“我已满 18 岁”。
4. 把刚才复制的密钥粘贴到 API key 那一栏。
5. 点“进去”，就可以开始聊天了。

小提示：

- 每次打开页面先只显示画面，点一下屏幕，对话框和按钮才会出来。
- 点一下对话框可以翻到下一句。
- 右上角的“隐藏”可以把对话框和按钮收起来，只看画面；再点一下屏幕就恢复。
- L 会带你在家里的卧室、客厅、厨房、书桌和窗边之间走动，背景会跟着换，白天和晚上的画面也不一样。
- 左下角的“照片”可以发图给他看。
- 右上角的“记录”可以翻看之前的对话。
- 可以让 L 卖个萌、撒个娇给你看，会有特别的画面。
- 屏幕右侧有“去酒吧”和“去画室”。去不去、去几次，后果自负。
- 可以直接用手指点 L：点头发是摸头，点脸是摸脸，点肩膀到腰是碰他的身体。每个部位他都有好几种反应，多点几次会不一样。这些反应是即时的，不花 API 费用。之后聊天时他会记得你刚才碰过他。
- 在酒吧里，右侧有“真心话”，可以和左见猜拳（先选石头、剪刀或布，再点“出拳”）：你赢了就问他一个问题，他赢了就换他问你。第一局开始时会换到卡座去玩。
- 在画室里，右侧有“编头发”，可以给林创扎高双马尾、低双马尾、侧低马尾、高马尾、双麻花辫，画面会换成对应的样子。扎好以后可以换别的发型，也可以选“拆掉”恢复原样。

## 费用大概多少

按用量计费，没有月费。聊得越久、每条带的上文越多，单条会略贵一些。

- **Claude 线路**：粗略估计每条消息几美分，发照片的那一条会更贵。
- **DeepSeek 线路**：粗略估计每条消息几分钱人民币。

这只是估算，实际金额以各自平台上的用量和余额为准，建议刚开始多看几次。

## 你的数据存在哪里

- 名字、聊天记录、L 记住的事、你的 API key，全部只保存在**你自己这台设备的浏览器里**。
- API key 和聊天内容只会发给你所填 key 对应的那一家（Anthropic 或 DeepSeek）的服务器，用来生成回复。作者看不到，也收不到。
- 换设备、换浏览器或清除浏览器数据后，记录就没有了，需要重新填写。
- 想从头开始或更换密钥：在输入框里连续发送两次 `全部清空`。

安全建议：

- 不要把 API key 发给任何人，也不要截图发到群里。
- 给这个页面单独建一个密钥，不用了就在平台上删掉它。

## 常见问题

**点“进去”没反应**
看一下按钮上方有没有红色提示。常见原因是没勾“我已满 18 岁”，或者粘贴密钥时带进了空格、换行。

**提示“这个 API key 用不了”**
密钥没复制完整、已过期或已被删除。回到平台新建一个，重新填写。

**提示“发得太快了，或者 API 的额度用完了”**
等一会儿再试。还不行就去平台看看余额。

**提示“API 账户的余额用完了”**
去平台充值后再发一次，聊天记录不会丢。

**提示“连不上 Claude 的服务器”或“连不上 DeepSeek 的服务器”**
检查网络。Claude 在中国大陆、香港、澳门无法使用，这些地区请用 DeepSeek 线路。

**发出去以后一直显示“他在想……”**
这是在等回复。DeepSeek 线路开着深度思考，每条要多等几秒到十几秒，属于正常情况。

**想从一家换到另一家**
连续发送两次 `全部清空`，再填另一家的 key。注意聊天记录和他记住的事也会一起清掉。

**L 忘了我以前说过的事**
他能原样记住最近的 60 条消息，更早的内容会被他整理成要点长期记住。很久以前随口说的小细节可能会被忘掉，重要的事可以再对他说一次。
